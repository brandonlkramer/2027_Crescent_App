Crescent roster tool

Runs only on this computer. This page is technically blocked from connecting to the internet, so roster files you open here are never sent anywhere. Files it creates go to your Downloads folder.

1. Create student IDs for a class

  1. In the Crescent admin page, Student IDs tab: Download current ID list (IDs only, no names). This avoids giving two students the same ID.
  2. Here: choose the class roster (CSV, first row = column names, e.g. student_number,name) and the ID list, and type the class label.
  3. Keep roster_…_with_IDs.csv on your computer. Upload ids_….csv in the admin page. Print the ID slips for students.

2. Add names to quiz results

  1. In the admin page, download a quiz's CSV or Item CSV (IDs only).
  2. Here: choose that file and the matching roster_…_with_IDs.csv file(s). You can choose several rosters at once.
